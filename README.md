# Flashwise

Небольшое server-rendered приложение для создания и изучения карточек.

## Запуск

Требуется Node.js 18 или новее.

```powershell
npm install
Copy-Item .env.example .env
npm start
```

Откройте `http://localhost:3000/` в браузере. Не открывайте файлы из `views` через двойной клик или Live Server: это серверные EJS-шаблоны с расширением `.html`, и при прямом открытии браузер покажет служебный код шаблона вместо страницы. При первом запуске приложение создает базу MySQL `quizlet` и таблицы пользователей, колод и карточек. Для подключения используются переменные `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD` и `DB_NAME` из `.env`.

## Возможности

- регистрация с bcrypt-хешированием паролей;
- вход по логину и выход с уничтожением сессии;
- возврат на исходный защищенный URL после входа;
- создание колод, добавление и удаление карточек;
- study mode с переворотом карточки, клавиатурным управлением и навигацией;
- серверная проверка владельца, включая HTTP 403 для чужих колод;
- адаптивный SSR-интерфейс на EJS без frontend-фреймворка; шаблоны хранятся в `views/*.html`;
- MySQL через `mysql2` с каскадным удалением связанных записей.
